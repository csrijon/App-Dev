# Phase 2 — CMS Mapping (based on actual website)

Sections → Admin Page → Prisma Model → API → Socket Event
- Hero → /admin/hero → Hero → /api/hero → hero:updated
- FeaturedCreators → /admin/featured-creators → Creator → /api/creators → creator:updated
- Testimonials → /admin/testimonials → Testimonial → /api/testimonials → testimonial:updated
- CategoryCards → /admin/categories → Category → /api/categories → category:updated
- CTA / Footer links → /admin/settings → SiteSettings → /api/settings → settings:updated
- Contact / About pages → /admin/pages or static
